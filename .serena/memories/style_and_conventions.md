# Style And Conventions
- Frontend uses JavaScript/JSX with React function components and hooks.
- Existing frontend style: concise components, 4-space indentation, CSS in companion files, no TypeScript.
- Backend uses Python modules with simple docstrings and straightforward FastAPI route definitions.
- Tests use pytest with direct assertions and lightweight fixtures in `backend/tests/conftest.py`.
- Prefer minimal, focused changes and keep UI aligned with the current visual language instead of redesigning established screens.
- For code search in this repo, prefer `rg`.
